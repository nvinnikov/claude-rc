# Доставка — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поставить тулзу и приложение одной командой — себе, по ссылке на релиз и через Homebrew.

**Architecture:** Версия одна на всё, источник — `pyproject.toml`. Цели `make install` ставят локально. Тег `v*` запускает workflow, который проверяет совпадение версии с тегом, гоняет гейт, собирает `.app` на macOS-раннере и прикладывает артефакты к релизу. Формула и cask для Homebrew лежат в репозитории, копируются человеком в свой tap.

**Tech Stack:** Make, GitHub Actions (`ubuntu-latest` и `macos-latest`), `uv build`, `ditto`, Homebrew Formula/Cask на Ruby.

**Spec:** `docs/superpowers/specs/2026-08-18-delivery-design.md`

## Global Constraints

- Ветка работы: `feat/delivery`, ответвлена от `feat/menubar-app`.
- Ни `clauderc/`, ни `app/Sources/` в этой части не меняются: доставка ничего не переписывает, она только упаковывает.
- Комментарии и сообщения коммитов — русские; код, идентификаторы и содержимое workflow — английские.
- Комментарии только там, где решение неочевидно.
- Коммиты атомарные, Conventional Commits; в теле — **почему**, а не что.
- Никаких `git commit --amend` и `git rebase`.
- **Бота не запускать.** На машине работает живой поллер; второй получит от Telegram конфликт.
- Тег не создавать и не пушить: релиз — действие человека, а не наше.

### Task 1: `make install`

**Files:**
- Modify: `Makefile`
- Modify: `README.md`

**Interfaces:**
- Consumes: цель `app` из части 2, точка входа `claude-rc` из части 1
- Produces: цели `install-tool`, `install-app`, `install`

- [ ] **Step 1: Добавить цели**

```make
# Тулза нужна и сама по себе (например, на машине без графики), приложение без
# неё бессмысленно — отсюда разделение и зависимость.
install-tool:
	uv tool install --force .

install-app: install-tool app
	@if pgrep -f 'ClaudeRCMenu' >/dev/null; then \
		echo "Гашу запущенное приложение: иначе cp положит файлы под работающим процессом."; \
		pkill -f 'ClaudeRCMenu'; sleep 2; \
	fi
	rm -rf /Applications/ClaudeRC.app
	cp -R app/build/ClaudeRC.app /Applications/ClaudeRC.app
	@echo "Готово: /Applications/ClaudeRC.app"

install: install-app
```

Добавь `install`, `install-tool`, `install-app` в `.PHONY`.

- [ ] **Step 2: Проверить прогоном**

```bash
make install
ls -d /Applications/ClaudeRC.app
/usr/libexec/PlistBuddy -c "Print :CFBundleShortVersionString" /Applications/ClaudeRC.app/Contents/Info.plist
cd /tmp && claude-rc version && cd -
```

Ожидание: бандл на месте, версия совпадает с `pyproject.toml`, `claude-rc` работает вне репозитория.

**Приложение после установки не запускай** — на машине живой бот, а приложение поднимет второго.

- [ ] **Step 3: Описать в README**

Секция про установку: `make install` одной командой, что она делает, и что после неё приложение надо один раз открыть и поставить галочку `Launch at login`. Скажи прямо, что `make install` гасит запущенное приложение — человек не должен удивляться исчезнувшей иконке.

```bash

Цель гасит запущенное приложение перед копированием: иначе cp кладёт файлы под
```

### Task 3: Релизный workflow

**Files:**
- Create: `.github/workflows/release.yml`
- Modify: `README.md`

**Interfaces:**
- Consumes: `make check`, `make app`, версия из `pyproject.toml`
- Produces: релиз с `ClaudeRC.app.zip`, sdist и wheel

- [ ] **Step 1: Написать workflow**

Создай `.github/workflows/release.yml`:

```yaml
name: Release

on:
  push:
    tags: ["v*"]

permissions:
  contents: write

jobs:
  verify:
    name: Verify version and gate
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v5
      - run: uv sync --all-groups --frozen
      # Единственная защита от релиза, в котором `claude-rc version` печатает
      # не то, что написано на странице релиза.
      - name: Tag must match pyproject version
        run: |
          tag="${GITHUB_REF_NAME#v}"
          version="$(sed -n 's/^version = "\(.*\)"/\1/p' pyproject.toml | head -1)"
          if [ "$tag" != "$version" ]; then
            echo "Тег $GITHUB_REF_NAME не совпадает с версией $version в pyproject.toml" >&2
            exit 1
          fi
      - name: Install tmux
        run: sudo apt-get update && sudo apt-get install -y tmux
      - name: Configure git
        run: |
          git config --global user.email ci@example.com
          git config --global user.name CI
      - run: uv run ruff format --check .
      - run: uv run ruff check .
      - run: uv run mypy
      - run: uv run pytest

  package:
    name: Build python package
    needs: verify
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v5
      - run: uv build
      - uses: actions/upload-artifact@v4
        with:
          name: python-package
          path: dist/*

  bundle:
    name: Build app bundle
    needs: verify
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - run: make app-test
      - run: make app
      # ditto, а не zip: обычный zip теряет права и симлинки бандла, и подпись
      # после распаковки перестаёт проверяться.
      - name: Zip bundle
        run: ditto -c -k --keepParent app/build/ClaudeRC.app ClaudeRC.app.zip
      - uses: actions/upload-artifact@v4
        with:
          name: app-bundle
          path: ClaudeRC.app.zip

  publish:
    name: Publish release
    needs: [package, bundle]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/download-artifact@v4
        with:
          path: artifacts
      - name: Checksums for the Homebrew tap
        run: |
          echo "Скопируй в формулу и cask:"
          find artifacts -type f \( -name '*.zip' -o -name '*.tar.gz' \) -print0 \
            | xargs -0 shasum -a 256
      - uses: softprops/action-gh-release@v2
        with:
          files: |
            artifacts/app-bundle/ClaudeRC.app.zip
            artifacts/python-package/*
          generate_release_notes: true
```

- [ ] **Step 2: Проверить синтаксис**

```bash
ruby -ryaml -e "YAML.load_file('.github/workflows/release.yml'); puts 'yaml ok'"
```

- [ ] **Step 3: Проверить, что проверка версии действительно ловит расхождение**

Логику из шага проверки прогони локально в обе стороны:

```bash
version="$(sed -n 's/^version = "\(.*\)"/\1/p' pyproject.toml | head -1)"; echo "версия=$version"
for tag in "v$version" "v9.9.9"; do
  t="${tag#v}"
  if [ "$t" != "$version" ]; then echo "$tag -> падает, верно"; else echo "$tag -> проходит, верно"; fi
done
```

Ожидание: совпадающий тег проходит, несовпадающий падает.

- [ ] **Step 4: Описать в README**

Секция про релиз: тег `v<версия>` запускает сборку; версия обязана совпадать с `pyproject.toml`; скачанный `.app` при первом запуске требует снять карантин:

```bash
xattr -dr com.apple.quarantine /Applications/ClaudeRC.app
```

Объясни **почему** — подписи Developer ID у нас нет, это осознанный размен, а не поломка.

- [ ] **Step 5: Коммит**


### Task 4: Homebrew tap

**Files:**
- Create: `packaging/homebrew/claude-rc.rb`
- Create: `packaging/homebrew/claude-rc-app.rb`
- Create: `packaging/homebrew/README.md`
- Modify: `README.md`

**Interfaces:**
- Consumes: артефакты релиза из задачи 3
- Produces: формула и cask, готовые к копированию в `nvinnikov/homebrew-tap`

- [ ] **Step 1: Написать формулу**

Создай `packaging/homebrew/claude-rc.rb`:

```ruby
class ClaudeRc < Formula
  include Language::Python::Virtualenv

  desc "Telegram bot that launches Claude Code sessions with Remote Control"
  homepage "https://github.com/nvinnikov/claude-rc"
  url "https://github.com/nvinnikov/claude-rc/releases/download/vVERSION/claude_rc-VERSION.tar.gz"
  sha256 "REPLACE_WITH_SHA256"
  license "MIT"

  depends_on "python@3.12"
  # Без tmux сессию не поднять: `claude --remote-control` требует tty.
  depends_on "tmux"

  def install
    virtualenv_install_with_resources
  end

  test do
    assert_match "claude-rc", shell_output("#{bin}/claude-rc --help")
  end
end
```

- [ ] **Step 2: Написать cask**

Создай `packaging/homebrew/claude-rc-app.rb`:

```ruby
cask "claude-rc-app" do
  version "VERSION"
  sha256 "REPLACE_WITH_SHA256"

  url "https://github.com/nvinnikov/claude-rc/releases/download/v#{version}/ClaudeRC.app.zip"
  name "ClaudeRC"
  desc "Menu bar app that keeps the claude-rc bot running"
  homepage "https://github.com/nvinnikov/claude-rc"

  # Приложение без тулзы бессмысленно: оно только запускает `claude-rc bot`.
  depends_on formula: "claude-rc"
  depends_on macos: ">= :sonoma"

  app "ClaudeRC.app"

  zap trash: [
    "~/.claude-rc",
    "~/Library/LaunchAgents/com.nvinnikov.claude-rc-app.plist",
  ]
end
```

Обрати внимание: `zap` не трогает `~/.config/claude-rc/config.toml`. Это намеренно — там боевой токен бота, и удалять его при удалении приложения нельзя. Напиши это комментарием.

- [ ] **Step 3: Написать инструкцию**

Создай `packaging/homebrew/README.md`: что это за файлы, куда их копировать (`Formula/` и `Casks/` в репозитории `nvinnikov/homebrew-tap`), что `VERSION` и `REPLACE_WITH_SHA256` подставляются из вывода релизного workflow, и что репозиторий tap создаётся человеком вручную — автоматического пуша нет намеренно, иначе пришлось бы держать здесь токен с правом записи в чужой репозиторий.

- [ ] **Step 4: Проверить синтаксис Ruby**

```bash
ruby -c packaging/homebrew/claude-rc.rb
ruby -c packaging/homebrew/claude-rc-app.rb
```

- [ ] **Step 5: Описать в README проекта**

Три способа установки одним списком: `make install` для себя, скачивание из релиза, `brew install nvinnikov/tap/claude-rc-app`. Про последний скажи честно, что tap ещё надо создать.

- [ ] **Step 6: Коммит**

```bash
git add packaging README.md
git commit -m "$(cat <<'MSG'
feat: формула и cask для Homebrew

Автоматического пуша в tap нет намеренно: это второй репозиторий, и токен с правом
записи в него пришлось бы держать в секретах этого. Размен не в нашу пользу.
MSG
)"
```
